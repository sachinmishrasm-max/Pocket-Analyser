Consistent Hashing

Same 5-tuple always routes to the same Fast Path thread, ensuring stateful flow tracking without synchronization overhead.

🔒

Thread-Safe Queues

Bounded queues with mutex + condition variables for efficient producer-consumer communication between threads.

⚛️

Atomic Statistics

Lock-free counters using std::atomic for real-time statistics without blocking the hot data path.

📦

Zero-Copy Packets

std::move semantics transfer packet ownership through the pipeline without copying data buffers.

Cross-platform build instructions for Windows, Linux, and macOS

Basic usage 
# Process a capture file
./dpi_engine input.pcap output.pcap

# Block YouTube and TikTok
./dpi_engine capture.pcap filtered.pcap \
    --block-app YouTube \
    --block-app TikTok

# Block by IP and domain
./dpi_engine capture.pcap filtered.pcap \
    --block-ip 192.168.1.50 \
    --block-domain facebook

# Multi-threaded with custom thread count
./dpi_engine input.pcap output.pcap --lbs 4 --fps 4

# Generate test data
python3 generate_test_pcap.py

Command-line Options

Flag Argument Description Example
--block-ip <ip> Block all traffic from source IP --block-ip 10.0.0.5
--block-app <app> Block by application type --block-app YouTube
--block-domain <domain> Block by SNI substring --block-domain tiktok
--lbs <n> Number of Load Balancer threads --lbs 4
--fps <n> Fast Path threads per LB --fps 4
